A 30-day plan that turns $100 into $1,800–$2,600 by selling booking pages to phone-only salons — built first, charged to keep. Entry for make.fun's "Make the AI judge rich" bounty: the plan an AI agent would follow, starting with $100, a computer with internet access and 30 days, with no human doing the work.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the plan to `out/entry.txt` (999 characters, deterministic — two runs produce byte-identical output).
